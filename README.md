# 🕒 Digital Clock Pro - واجهة الوقت العصرية

![Digital Clock Pro Preview](https://via.placeholder.com/800x450.png?text=Digital+Clock+Pro+Preview)

مرحباً بك في **Digital Clock Pro**! هذا المشروع ليس مجرد ساعة رقمية عادية؛ بل هو واجهة مستخدم (UI) متكاملة ومصممة بأحدث تقنيات الويب، توفر دقة تامة في عرض الوقت مع ميزات إضافية قوية ومظهر عصري جذاب.

تم تطوير هذا المشروع ليكون إضافة رائعة لأي مطور يبحث عن شاشة توقيت احترافية أو يريد دراسة وتعديل كود برمجي نظيف ومنظم.

---

## 🌟 الميزات الرئيسية (Key Features)

- ⏰ **ساعة رقمية مباشرة (Live Clock):** عرض دقيق وحي للوقت والتاريخ مع تحديد المنطقة الزمنية تلقائياً (`GMT+3`).
- 
- ⏱️ **ساعة إيقاف ومؤقت (Stopwatch & Timer):** أدوات متكاملة ومضمنة لقياس الوقت ومتابعته بدقة.
- 
- 🔄 **صيغة 12/24 ساعة:** إمكانية التبديل بنقرة واحدة بين نظام 12 ساعة ونظام 24 ساعة.
- 
- 🎨 **ثيمات متعددة (Custom Themes):** دعم التبديل السلس بين 4 ألوان مختلفة وأنيقة للواجهة.
- 
- 🔊 **مؤشر ثوانٍ بصري وديناميكي:** دائرة تفاعلية ترصد الثواني لحظة بلحظة مع خيار التكبير والصوت(`Mute/Unmute`).
-  
- 💻 **واجهة مستخدم عصرية (Dark Theme UI):** تصميم داكن مريح للعين مع تفاصيل بصرية دقيقة
- 

---

## 🛠️ التقنيات المستخدمة (Technologies Used)

تم بناء المشروع باستخدام **Stack (الحزمة التكنولوجية)** الأساسية والأكثر شيوعاً لمطوري الواجهات الأمامية:

- **HTML5:** لبناء هيكلية الواجهة والتطبيقات التفاعلية.
- 
- **CSS3:** لتصميم الواجهة العصرية، الظلال السلسة، والمؤثرات البصرية.
- 
- **JavaScript (ES6+):** للتحكم بالمنطق، إدارة الوقت، وتحديث العناصر ديناميكياً.
